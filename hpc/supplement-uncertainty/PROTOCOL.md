# Supplemental uncertainty analysis

Author: James Edward Ball

Freeze this directory before any supplemental scores. Existing primary study files remain unchanged. These analyses follow completion of their respective primary jobs and use the admitted frozen cohorts.

## Training-block fit stability

Run separately for fresh EuroSAT and global WorldCover cohorts. Evaluate appearance, Clay, Prithvi 300M and Prithvi 100M with mean pooling and all three existing text references. Use exactly 20 training-block draws, generated by seed 20261016 plus replicate index. Draw the original number of training blocks with replacement and retain every scene in each selected block, including repetitions. Share each draw across all models and language references. Retain unsupported draws explicitly; never replace them.

Refit every ridge mapping and select alpha using the unchanged validation set only, with the primary alpha grid and held-out category folds. Evaluate the unchanged test set. Use the full primary fitting cohort subject only to the block resampling. Retain each replicate and all validation candidates. Show all differences from appearance, their median, observed minimum and maximum, and fraction above zero. Twenty draws describe sensitivity to fitting geography; their empirical range is not a population confidence interval. This stage does not resample validation choices or test geography jointly.

## Internal intervention uncertainty

Use the completed internal experiment's fixed directions, selected clean readouts and 300-image test subset. The primary dose is 1. Compare each target-category intervention with the average of its three energy-matched random controls, and separately with its norm-only control. Within each category, average target-category query AP differences within geographic blocks and then across blocks; average the ten category effects equally.

Use 2,000 common geographic-block bootstrap draws, seed 20261016. A draw missing any target category is unsupported and remains recorded. Report ordinary conditional intervals and simultaneous intervals for one fixed family of 18 contrasts: three encoders, three text references and two control comparisons. The simultaneous interval radius is the 95th percentile of the largest absolute centred bootstrap error across the family, in AP units. This is a conditional bootstrap procedure, not a guarantee of unconditional coverage. Save every bootstrap draw.

The intervention intervals condition on learned directions, readouts, validation choices, selected scenes and encoder checkpoints. They do not establish a unique circuit or general semantic capability. No best-performing reference, model, category or dose is selected after results.
